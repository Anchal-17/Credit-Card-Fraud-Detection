💳 Credit Card Fraud Detection

This project aims to detect fraudulent credit card transactions using machine learning techniques, specifically the Random Forest Classifier. The model is trained on the popular Kaggle Credit Card Fraud Detection Dataset, which contains transactions made by European cardholders in September.

🧠 Overview

The objective of this project is to build a classification model that accurately identifies fraudulent transactions from a highly imbalanced dataset.
Key steps performed in the project include:

Data Loading & Exploration
Importing and displaying data using pandas and numpy.
Exploring dataset features and summary statistics.
Data Analysis
Checking for class imbalance.
Visualizing correlations using a heatmap (seaborn and matplotlib).
Model Building
Splitting the dataset into training and testing sets.
Applying a Random Forest Classifier for fraud detection.
Model Evaluation
Measuring Accuracy, Precision, Recall, and F1-Score.
Displaying the Confusion Matrix for better visualization of results.
